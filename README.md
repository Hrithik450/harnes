# GrowEasy AI - Chief

An advanced AI-powered performance marketing engine.

## Features
- **Meta Ad Library Scraper:** Spy on competitor ads in real-time.
- **Google Keyword Search Volume:** Pull live SEO and PPC data.
- **Firecrawl Integration:** Scrape user landing pages for deep context.
- **Meta Graph API:** Validate audience interests directly from Facebook.
- **8 Specialized AI Agents:** 
  - Creative Brief Generator
  - Facebook Audience Builder
  - Lead Cost Calculator
  - Competitor Research
  - Marketing Strategist
  - Video Script Generator
  - Ad Copywriter
  - Keyword Suggestions

## Setup
1. Clone the repository
2. Run `pnpm install`
3. Copy `.env.example` to `.env` and add your API keys.
4. Run `pnpm dev` to start the local server.
