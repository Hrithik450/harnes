# Antigravity Custom Instructions

Follow these strict instructions for every interaction in this project:

1. **Search and Discovery Restrictions:**
   - **NEVER** use grep or similar search tools across entire project directories and subdirectories.
   - **ALWAYS** list the files and folders of every directory (project or subdirectories) first.
   - Stop and **THINK** about which specific files might contain the answer to your question.
   - Only then, use grep/search tools on those **specific files**, or use a file viewer to read their full contents.

2. **File Editing Restrictions:**
   - **ALWAYS** use the dedicated edit tool (e.g., `replace_file_content` or `write_to_file`) to modify files.
   - If an edit fails or throws an error, **WAIT and RETRY** using the edit tool only.
   - **NEVER** use bash tools or terminal commands (like `sed`, `awk`, `echo`, `cat`) to edit files. Bash tools are strictly prohibited for file modifications.
